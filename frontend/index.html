LR4 Demo

Multimodal Diffusion Dataset Service

Контейнерный ML-сервис для генерации синтетического мультимодального датасета. В стенд уже интегрированы интерфейс, inference API, background worker, PostgreSQL, MinIO, Prometheus и MLflow. Для демонстрации доступны одиночная генерация, batch job по теме, история запросов и live-мониторинг.

Проверка health... Frontend: :3000 API: :8000 Prometheus: :9090 MLflow: :5000 MinIO: :9001

Генерация одного изображения

Онлайн-инференс микросервиса: отправляем prompt в /generate, получаем PNG, seed, latency и путь к артефакту.

Догенерация по теме

Основной сценарий проекта: указываешь недостающий тип объектов, например мебель, и размер партии до 1000 изображений. В фоне создаётся generation-job, UI показывает статус, первые preview и manifest CSV.

Компоненты стенда

Frontend API Docs Health Metrics Prometheus MLflow MinIO Console
Frontend Веб-интерфейс для запуска генерации и демонстрации работы сервиса.
Inference API FastAPI-сервис с endpoint'ами /generate, /generation-jobs, /metrics.
Generation Worker Фоновая batch-генерация для больших партий датасета.
PostgreSQL Хранение истории запросов, generation jobs и metadata артефактов.
MinIO Object storage для PNG и manifest CSV.
Prometheus + MLflow Runtime-мониторинг и experiment tracking.

Метрики для защиты ЛР4: количество обращений, состояние базы, загрузка diffusion-модели и latency одиночной генерации.

Что показывать на защите

  1. Показать, что контейнеры подняты и UI открывается.
  2. Запустить одиночную генерацию через /generate.
  3. Создать batch job по теме через /generation-jobs.
  4. Открыть manifest CSV и историю генераций.
  5. Показать обновление /metrics, Prometheus и MLflow.
  6. Открыть MinIO и показать, что PNG и manifest реально сохранены.
